# Track Pay: instructions for AI coding agents

Before doing anything, read `AI-RULES.md`, then `BUILD-TODO.md`, then `GUARDRAILS.md`. Continue at the current step of the active track. Work on one step at a time, run the checks, update `BUILD-TODO.md`, report in the format in `AI-RULES.md`, and wait for approval.

Two plans, in order: the project plan (`ARCHITECTURE-BUILD-PLAN.md`) first, then the design plan (`DESIGN-BUILD-PLAN.md`, Part B). Do not start the design plan until the working app (milestone M1) is approved.

Never guess. If a spec is silent, ask.
